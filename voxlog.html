VoxLog
讓錄音成為可用的文字。

從語音辨識到逐字稿編輯、AI 校正與會議摘要，把分散的處理步驟整合在一個桌面工作區。

查看安裝方式 ↓GitHub 原始碼 ↗

macOS／Windows 桌面專案 · Python / PySide6 · AI 協作開發

01 / THE PROBLEM

轉成文字，只完成了一半。

錄音轉出逐字稿後，通常還需要找片段、修正辨識結果、整理摘要與製作字幕。VoxLog 把這些後續工作放進同一個工作區。

02 / MY CONTRIBUTION

把模型能力接成操作流程。

我負責工具規劃與 AI 協作開發，整合轉錄引擎、桌面介面、模型選擇、文字工作區與輸出流程，並提供不同電腦環境的安裝指引。

03 / THE DESIGN CHOICE

讓資料去向有明確選擇。

語音辨識在本機執行；AI 校正與摘要可選雲端服務或本機模型。選用雲端 AI 時，逐字稿文字會傳送到使用者設定的服務。

GET STARTED

在自己的電腦使用 VoxLog。

從 GitHub 取得專案，依 macOS 或 Windows 說明安裝。輕量版以 whisper.cpp 進行語音辨識；需要說話人分離時，可參考完整版的模型與環境設定。
