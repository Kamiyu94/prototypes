專案管理儀表板

讓分散的工作，
成為看得懂的管理資訊。

主管需要知道的不只是任務清單，而是哪些專案有進展、哪裡需要協調、接下來由誰推進。這個儀表板將工作紀錄整理成專案、案件與會議三種視角。

01 / THE PROBLEM

資料很多，卻不容易做決定。

團隊的日常紀錄分散在不同工作項目，主管難以快速辨識整體進展、停滯與風險；每次會議前還要重新整理報告。

02 / MY CONTRIBUTION

把現場需求轉成管理視角。

我負責管理需求釐清、儀表板建置與持續迭代，整理專案與案件的關聯、風險、Owner 與下一步。原工作版本曾經歷協作優化；此公開版另行重製介面與資料。

03 / THE DESIGN CHOICE

資訊能彙整，也能回到細節。

總覽保留專案完成度與有效樣本數；案件可依部門、負責人與狀態追蹤；會議頁聚焦到期與人工風險，再挑選專案組成管理報告。

TRY THE WORKFLOW

從風險，走到下一步。

在「會議焦點」查看需要協調的案件，編輯風險與下一步；回到「專案總覽」選取呈報項目、調整順序，再預覽 A4 報告。也能修改「模擬今天」，觀察到期燈號的變化。

公開版採用深藍、金色與淺色工作區，重新安排上方導覽及卡片，與需求審核工作台形成不同的操作視角。
